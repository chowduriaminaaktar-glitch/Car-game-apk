# Stormline | Weather-Driven Rally Simulator (Android APK)

Stormline is a weather-driven rally simulator built for Android using Kotlin, Jetpack Compose, hardware-accelerated Canvas simulation, and real-time gyroscope/rotation controls.

---

## 📥 How to Download the APK File from GitHub

If you pushed this project to GitHub or created a GitHub Release, here is how to get your `.apk` file:

### Method 1: Automatic Download from GitHub Releases
1. In your GitHub repository, look at the right sidebar and click **Releases** (or navigate to `https://github.com/YOUR_USERNAME/YOUR_REPO/releases`).
2. Click on the latest release (e.g. `v1.0`).
3. Scroll down to the **Assets** section.
4. Click on **`Stormline.apk`** to download it directly to your phone or computer!

> 💡 **Note**: When you publish a release or create a new tag on GitHub, GitHub Actions will automatically compile the APK and attach `Stormline.apk` to the Assets list within 2–3 minutes.

---

### Method 2: Download Directly from GitHub Actions (No Release Required)
You can download the APK anytime without creating a release:
1. In your GitHub repository, click on the **Actions** tab at the top.
2. In the left sidebar, click **Build & Release Android APK**.
3. Click on the latest workflow run (with the green checkmark ✔️).
4. Scroll down to the bottom of the page to find the **Artifacts** section.
5. Click on **`app-debug`** — this downloads the installable `app-debug.apk` directly to your device!

---

### Method 3: Trigger a Manual Build Anytime
1. Go to the **Actions** tab on GitHub.
2. Click **Build & Release Android APK** on the left.
3. Click the **Run workflow** dropdown on the right and click the green **Run workflow** button.
4. Wait ~2 minutes for the build to finish, then download the APK under **Artifacts**.

---

### Method 4: Download Directly from AI Studio
1. In the AI Studio interface, click on the project settings or export menu.
2. Select **Generate APK / Export** to download the compiled `.apk` file directly to your device.

## 🏎️ Features
- **5 Rally Stages**: Valley Circuit, Desert Tempest, Arctic Blizzard, Coastal Typhoon, and Nightfall Sprint.
- **Smart Rotation System**: Animated cockpit guidance in portrait; edge-to-edge immersive racing when rotated to landscape.
- **On-Screen Touch Controls**: Precision steering paddles, progressive throttle, brake, handbrake drift, and boost.
- **Dynamic Weather & Aquaplaning**: Torrential downpours, dry racing lines, gravel drifts, and black ice.
- **Offline Ready**: Fully self-contained simulator with zero network latency.
